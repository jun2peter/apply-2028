MIT Media Lab(과 함께 지원할 학교) 원서 준비를 한눈에 보는 대시보드입니다.
내용은 전부 구글 시트에 있고, 이 사이트는 시트를 읽어서 보여 주기만 합니다.

- 시트: https://docs.google.com/spreadsheets/d/1wrqY1v3PXdXruQnuOd3c7qaC83z7hvpVQ5Oocj38bZ4/edit
- 사이트: https://jun2peter.github.io/apply-2028/

## 화면

| 화면 | 보이는 것 |
|---|---|
| 홈 | 1순위 학교 마감까지 남은 날, 2026-10 ~ 2028-09 타임라인, 지금 할 일, 원서 마감, 학교별 서류 진행, 포트폴리오, 영어 시험, 최근 기록 |
| 할 일 | 마감 달별로 묶은 할 일. 분류로 거르기, 끝난 일 숨기기 |
| 학교 | 학교 카드(마감, 원서비, 영어 기준, 추천서 수, 서류 진행, 맞는 이유) |
| 서류 | 서류 종류 × 학교 표 |
| 포트폴리오 | 상태별 작업 보드(후보 → 선정 → 글쓰기 → 자료정리 → 페이지완성) |
| 연구실 | 학교별 관심 연구실과 나와의 연결점 |
| 추천인 / 시험 | 추천서 진행, TOEFL 일정과 학교별 기준 |

각 줄 오른쪽 ↗를 누르면 시트의 그 줄이 열립니다. 시트에서 고치고 사이트로 돌아오면 자동으로 다시 읽습니다(또는 새로고침 버튼).

## 처음 한 번 할 일

1. **GitHub Pages 켜기**: 저장소 Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save. 1~2분 뒤 위 사이트 주소가 열립니다.
2. **시트 공유 확인**: 시트 오른쪽 위 공유 → 일반 액세스를 `링크가 있는 모든 사용자`, 역할은 **뷰어**로. 사이트는 로그인 없이 읽어야 해서 링크 공유가 필요하지만, 편집 권한까지 열 필요는 없습니다.

이 저장소는 공개라서 시트 주소도 공개됩니다. 연락처나 개인 정보는 시트에 적지 마세요.
